INCOME, EXPENSE & SAVINGS TRACKER (Vanilla HTML, CSS, and JS)
==============================================================

How to Run Offline:
1. Extract the contents of `kita-gastos-tracker.zip` into any folder on your computer, tablet, or phone.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).
3. Everything runs 100% offline — including the Savings Goal Calculator and Smart Budgeting Recommendations engine.

Key Pages (Accessible via the ☰ Three-Line Menu):
- Home: Dashboard overview with Total Income, Total Expenses, Remaining Balance, Total Saved in Goals, Weekly & Monthly summaries, and Recent Transactions.
- Records: Add, edit, delete, search, and filter transactions.
- Savings & Goals: Payday Salary Savings Helper, Savings Goal creation with automatic Per-Month / Per-Kinsenas / Per-Week / Per-Day required schedules, and Savings Deposit/Withdrawal Ledger.
- Built-in Calculator: Standard arithmetic keypad with calculation tape + Interactive Savings Goal & Deadline Calculator.
- Smart Recommendations: Data-driven budgeting rule advisor (50/30/20, 70/20/10, 60/20/20, 80/20) and personalized next-month category limits based on your past month or week records.
- Monthly & Weekly Reports: Interactive Monthly/Weekly chart, Expense by Category breakdown, and full Monthly & Weekly summary tables.
- Save & Load Files: Save backups to `.json` or `.csv` files, and load/restore `.json` or `.csv` files.
- History: Activity log with Undo for the most recently deleted record.

Included Files:
- index.html          : Main web application entry point
- style.css           : Mobile-first responsive Vanilla CSS stylesheet
- app.js              : Pure Vanilla JavaScript calculation, savings, recommendation, and file I/O logic
- sample-records.json : Sample backup file with transactions and savings goals
